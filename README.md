# Fraud Detection & Risk Analysis

## Project Overview
This project focuses on detecting suspicious financial transactions using data analytics, SQL, Python, and Power BI. The objective was to identify fraud patterns, risky transaction behaviors, and generate actionable fraud detection signals.

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Jupyter Notebook

---

## Project Objectives
- Analyze transaction behavior
- Identify fraudulent transaction patterns
- Create fraud detection signals
- Build interactive dashboards
- Generate risk scores for transactions

---

## Key Fraud Detection Signals
The project includes multiple fraud detection indicators:

1. Velocity Transactions Detection
2. Multiple Cards Usage Detection
3. Shared Card Detection
4. Night Hour Transactions Analysis
5. High Value Transaction Monitoring

---

## Dataset Information
The datasets contain transaction-level information including:
- Transaction amount
- Card usage patterns
- Transaction timestamps
- Merchant details
- Fraud risk indicators

---

## SQL Analysis
SQL was used for:
- Data cleaning

- Transaction filtering

Interactive Power BI dashboard includes:
- Fraud trend analysis

## Project Workflow
1. Data Collection

---

## Key Insights
- High-value night transactions showed increased fraud probability.
- Repeated card usage within short intervals indicated suspicious behavior.
- Shared cards across multiple accounts increased fraud risk.
- Velocity-based transaction monitoring improved fraud identification.
